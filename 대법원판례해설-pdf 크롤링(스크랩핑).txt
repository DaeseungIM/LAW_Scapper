[1차 프로프트 작성]
먼저 다음과 같은 프로젝트를 하고 싶은데, 수정하거나 변경할 내용이 있으면 검토해서 자세하게 프로프트 추천해줘
구글 AI Studio 를 이용하여 특정 사이트의 파일(특히 pdf)을 자동으로 다운로드하는 프로그램을 만들고 싶음
1. 먼저 법원도서관(https://library.scourt.go.kr/)에서 [대법원판례해설]자료 중 관련 PDF 파일을 모두 다운로드
2. 그동안 구글 AI Studio를 이용하여 여러 차례 시도를 해 보았지만 실패를 거듭하였음
3. 대표적인 실패는 다운로드를 했지만, 원하는 PDF파일이 아니었음

4. 먼저 웹크롤링 방법에 대한 사이트(https://ejji.tistory.com/17)를 참고해서, 진행을 하고 싶고
5. 진행단계에서 모든 단계를 전부 해결하면 좋겠지만, 중간에 예를 들어 devtools에서 필요한 정보 필요할 경우, 구체적으로 어떤 메뉴에서 어떤 정보가 필요한지를 알려 주면, 확인하고 다음 단계로 넘어가는 방법으로 진행하여 성공적인 다운로드 방법을 찾았으면 함

6. 이러한 정보를 기반으로 하여 구글 AI Studio  에 한번에 또는 단계별로 진행할지 여부도 검토해서 필요한 사항을 정의하면 좋겠음


[1차 제미나이 답변내용]
###1단계###
우리는 Python의 Selenium 라이브러리를 사용하여 법원도서관(https://library.scourt.go.kr/ 또는 e-book 연동 페이지)에서 '대법원판례해설' 관련 PDF 파일을 자동으로 모두 다운로드하는 프로그램을 만들 거야.

그동안 단순 HTML 파싱으로 다운로드를 시도했으나 진짜 PDF 주소를 찾지 못해 실패했어. 따라서 이번에는 동적 크롤링 방식(Selenium)을 적용할 거야.

[1단계 목표]: 
목록 페이지에 접속한 뒤, 각 도서의 '상세보기' 버튼이나 '다운로드' 버튼이 담긴 HTML 구조를 인간(사용자)이 크롤러에게 직접 주입할 수 있도록 '목록 확인용 기본 스크립트'를 작성해 줘.

[조건]:
1. 크롬 드라이버를 Headless 모드가 아닌, 실제 브라우저 창이 뜨는 모드로 실행해 줘. (사람이 눈으로 검토하기 위함)
2. 사이트 접속 후, 동적 자바스크립트가 모두 로드될 수 있게 최소 5초간 대기(implicitly_wait 또는 time.sleep)하는 코드를 넣어줘.
3. 우선 지정된 URL에 접속하여 브라우저를 유지하는 코드까지만 작성하고, 다음 단계에서 내가 개발자 도구(DevTools)에서 수집한 정보를 입력할 수 있는 안내 메시지를 출력하도록 해줘.

###2단계###
1단계가 정상 작동해서 브라우저가 열렸어. 내가 개발자 도구(DevTools)의 Elements 메뉴에서 '다운로드(혹은 원문보기)' 버튼의 태그를 직접 카피해 왔어. 아래 태그 구조를 분석해서, 셀레니움이 이 버튼을 정확히 클릭하거나 내부 자바스크립트 함수를 강제로 실행(execute_script)하도록 유도하는 크롤링 핵심 함수를 짜줘.

[내가 복사한 DevTools 태그 정보]:
(여기에 마우스 우클릭으로 복사한 HTML 태그를 붙여넣으세요! 예: <a href="javascript:void(0);" id="downloadPdf"...>)

[수행할 작업]:
위 태그를 기준으로 버튼을 찾아 클릭 이벤트를 발생시키는 코드를 작성해 줘. 만약 클릭했을 때 크롬 브라우저 기본 다운로드 폴더로 실제 PDF가 저장되는 구조인지, 아니면 별도의 팝업창(가상 뷰어)이 뜨는 구조인지 판단할 수 있게 예외 처리를 꼼꼼하게 해 줘.

###3단계###
단일 파일 다운로드 메커니즘이 성공했어! 이제 이 작업을 목록 전체로 확장하려고 해.

[3단계 목표]:
1. 현재 페이지의 게시글 목록 개수(예: 10개)만큼 반복하여 상세페이지 진입 -> 다운로드 -> 뒤로가기(back)를 수행하는 루프를 만들어줘.
2. 한 페이지 작업이 끝나면 하단의 [다음 페이지(Next)] 버튼을 개발자 도구 기반으로 찾아서 클릭하고, 다음 목록을 크롤링하게 해줘.
3. 다운로드 속도가 너무 빠르면 법원 서버에서 IP를 차단하거나 매크로로 감지할 수 있으니, 다운로드 건당 `time.sleep(random.uniform(3, 7))` 값을 주어 사람처럼 불규칙하게 동작하도록 보완해 줘.
